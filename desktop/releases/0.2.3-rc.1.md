# Annotate 0.2.3-rc.1

Local release candidate for end-to-end testing. Not published, not Developer ID signed/notarized, and not Windows publisher-signed. Public distribution still requires the [licence review](../../docs/licence-review.md) to be resolved. Existing published release tags and files are unchanged.

## Changes

- Patched Next.js, Electron and vulnerable JavaScript runtime/build/test dependencies without a framework major-version change.
- Native language and panel-layout persistence independent of localhost ports; canonical-project-scoped pin annotation recovery copies with explicit restore/keep choices.
- Crashed/hung editor recovery, bounded close waiting, single-instance focus, and service cleanup after unexpected main-process termination.
- Help-menu logs, privacy-conscious diagnostic copying, bug reporting and release-page access; a public bug-report template and security-reporting instructions.
- One `0.2.3-rc.1` product version across hosts, embedded build identity, documented immutable version/tag policy, and target-specific dependency notice collection including the font licence.
- Paused video frame stepping now starts from the displayed frame rather than a playback clock that can lag by one frame.

## Validation ledger

Verification on the development Mac: 468 web unit tests, 104 sidecar tests, 36 native contract tests and all 48 Chromium workflow tests pass. The paused-frame regression also passed ten repeated browser runs. Typecheck, zero-warning lint and the production renderer build pass. Root and webapp npm audits report zero known vulnerabilities at the time of this check; this is not a complete binary/native security audit. The native workflow smoke passes import/cancel, clip/pin editing and saving, localization without media resets, detection requests, report exports and presentation playback. The recovery smoke passes new-origin relaunch, restoration through the UI, duplicate-instance refusal, renderer crash/reload and main-process termination cleanup.

Final packaged validation is recorded after rebuilding. A fixture and development-host test does not establish real-match tracking accuracy, clean-machine compatibility, Windows runtime behavior, or a completed licence review. The maintainer will run a real project end to end before approving release.
