# Annotate 0.2.2 Desktop Preview 2

Unsigned desktop evaluation builds for Apple Silicon Mac and Windows x64. Both installers were rebuilt on 2026-09-19 with the existing lowercase wordmark `a` as the application icon. Browser favicons and in-app branding are unchanged. The build also includes the latest desktop installation guide and retains the media-import, tracking-preview, homography, video-deletion and editor-session fixes.

This release is marked Latest with GitHub's prerelease flag off so it appears on the repository homepage. It remains an evaluation build with the limitations below, not a claim of signing or complete platform testing.

## Install

Download **Annotate-0.2.2-desktop.2-mac-arm64.dmg** below (976 MB), open it, and drag Annotate to Applications. Launch Annotate from Applications. Requires Apple Silicon (M1 or later) and macOS 14 or newer. Allow at least 3 GB for the app, plus space for the download, project videos and exports. Python, video tools, tracking and homography models, and the browser engine are bundled; no Homebrew, terminal setup or separate browser is required.

The app is ad-hoc signed, not Developer ID signed or notarized. macOS may require approval under System Settings > Privacy & Security. Do not disable Gatekeeper globally. If installation is blocked, report the exact warning.

On **Windows 10/11 x64**, download **Annotate-0.2.2-desktop.2-win-x64.exe** (931 MB), run the installer and open the desktop shortcut. It includes the runtime and models. There is no verified publisher signature; SmartScreen or organizational security policies may warn or block it. Do not disable Defender. Installation and first launch may take several minutes while libraries are scanned and initialized.

## Limits

- These are evaluation builds. Use copies of projects and do not edit one project simultaneously in the browser and desktop app.
- First launch can be slow. This refresh does not address the large installer footprint or cold-start performance.
- macOS Apple Silicon and Windows x64 only; no Intel Mac or native Windows ARM build.
- Project format remains `project.v2`. Annotate 0.1 projects are not supported.
- Recovery after abrupt crashes, broader platform testing and automatic updates remain unfinished.

## Verification

The Mac app passed automated project import, clip/pin editing, saving/reload, detection, PNG export, presentation playback and shutdown checks directly from its read-only DMG with a restricted executable search path. Bundled Python also ran YOLO detection, PnLCalib inference and H.264 encoding. Signature structure, disk-image integrity and runtime resource checks passed. These are build-Mac checks, not clean-machine or macOS 14 certification.

The Windows installer passed native-file and archive-integrity checks on the build Mac. The earlier desktop.1 preview was tried on Windows, but this refreshed build still needs Windows runtime testing.

Both installer assets, the matching source archive and checksums were replaced for this icon refresh. The filename/version remains `0.2.2-desktop.2`; at the maintainer's request, its tag was moved to the icon-build commit. Use the updated SHA-256 checksums to identify the new files. Existing browser release tags are unchanged. Mac service logs are at `~/Library/Application Support/Annotate/logs/services.log`; Windows logs are at `%APPDATA%\Annotate\logs\services.log`.
