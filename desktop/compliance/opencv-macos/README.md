# Mac OpenCV build evidence

This directory records the historical ARM64 OpenCV 4.11.0.86 wheel used by earlier Annotate packages. New Mac staging replaces its bundled native-library chain with a controlled source build; see [current build status](../../../docs/distribution-compliance.md#controlled-mac-opencv). This retained wheel evidence does not clear the historical wheel for distribution or replace any binary.

`provenance.json` pins every bundled dylib by its full SHA-256. For matched libraries it also records the original Homebrew bottle checksum, member path, Mach-O UUID, CPU type and instruction-section hashes. Wheel relocation changes install names and signatures, so the relocated whole-file hash differs from the original. Matching filenames or version numbers alone were not accepted. Unmatched libraries intentionally have no `original` record.

The `recipes/` files are unmodified `.brew/*.rb` members read from those checksum-verified bottles. Their checksums are in the manifest, and inline `__END__` patches are preserved. They are evidence, never executed by our collector. Historical registry source URLs are retained as discovery metadata but some no longer resolve; the original bottle and embedded recipe are the archived primary evidence. Homebrew's licence is reproduced from [the historical repository](https://github.com/Homebrew/homebrew-core/blob/c1fc61315283f9f0f87ef538aa21329eef57f37e/LICENSE.txt).

`inspectOpenCVMac` checks the current wheel against this lock before any Mac source evidence is assembled. Added, removed or changed dylibs fail the check rather than inheriting an earlier review. `verifyOriginalBottle` can repeat the original-bottle and recipe checks offline given a downloaded bottle. Public OCI blobs use anonymous registry authentication, obtainable from `https://ghcr.io/token?scope=repository:homebrew/core/FORMULA:pull&service=ghcr.io`; the token is only an HTTP credential and must not enter the evidence archive. Formula `openssl@3` uses registry path `homebrew/core/openssl/3`.

Verified source archives are separately pinned in `../sources.lock.json`. The source collector carries recipes, provenance and extracted notices into its output. A matched original build does not mean all its source dependencies are present: fetched resources, Rust crates, generated build inputs, unmatched libraries and replacement/relinking testing remain separate review items. The embedded FFmpeg's actual configuration enables GPL and version 3, regardless of the wheel's generic LGPL wording.

The 2026-10-26 follow-up matches 62 of 65 dylibs to 47 original bottles, including librist 0.2.11 and the original WebP bottle revision. GMP, x264 and ZeroMQ remain unmatched. The source lock also includes JPEG XL's exact sjpeg resource and expands the archived rav1e Cargo.lock into all 227 checksummed registry crate archives. This does not establish the source closure of other Rust components. An isolated modified libsoxr replacement test passed without altering the staged runtime; see [distribution compliance](../../../docs/distribution-compliance.md) for its scope and the remaining final-app tests.
