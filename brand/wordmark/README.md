# Annotate wordmark

The current identity: "annotate" in lowercase, set in IBM Plex Sans Bold,
the app's UI font. The abbreviated mark is the lowercase "a" from the
same setting. White on the app canvas `#0a0f18`; canvas navy on light.

| File | Use |
| --- | --- |
| `annotate.svg` | Transparent wordmark, white, for dark backgrounds. |
| `annotate-on-light.svg` | Transparent wordmark, navy, for light backgrounds. |
| `annotate-square.svg` | 400 x 400 lockup on the canvas colour, word at 74% width. Profile pictures. |
| `a.svg`, `a-on-light.svg` | Transparent lowercase a. |
| `a-icon.svg` | 240 x 240 lowercase a on the canvas colour. Favicon source. |
| `a-square.svg` | 400 x 400 lowercase a, padded for a round crop. Profile pictures. |
| `preview.svg` | Weights 700 and 600 side by side, on light, and both squares with the round crop shown. |

All text is converted to outlines, so nothing depends on the font being
installed. The glyphs were shaped with HarfBuzz using the font's own
kerning, at weight 700 with no extra tracking.

## Renders

`renders/` is regenerated by the build script.

- `renders/social/annotate-profile-{400,800}.png` and
  `renders/social/a-profile-{400,800}.png`, dark mode, square, sized for a
  Twitter/X profile picture (400 recommended, 800 for retina). Upload as
  is; the platform applies the round crop, which the 74% word width and
  the padded `a` are laid out for.
- `renders/favicon/` has `favicon.ico` (16, 32, 48), PNGs from 16 to 512,
  `apple-touch-icon-180.png`, and `icon.svg`, all from `a-icon.svg`.
- `renders/annotate-{dark,light}-2000.png` are transparent wordmarks at
  2000 px wide.

## Rebuilding

`tools/build.py` reads the variable font from
`webapp/node_modules/@fontsource-variable/ibm-plex-sans`, so the webapp
dependencies must be installed. It needs Python with `fonttools`,
`brotli` and `uharfbuzz`, plus ImageMagick's `magick` on PATH:

```
python3 -m venv .venv-brand && .venv-brand/bin/pip install fonttools brotli uharfbuzz
.venv-brand/bin/python brand/wordmark/tools/build.py
```

Weight, tracking and colours are constants at the top of the script.

## Usage note

Not used inside the app UI. Favicon and social profiles only.
